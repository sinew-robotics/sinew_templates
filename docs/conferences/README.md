# Venue and event delivery research

These documents summarize official pages reviewed on **2026-08-25**. They are dated background guidance for preparing delivery, not visual styles, Quarto profiles, or executable configuration. Reading one of these files does not change the deck, and visual styling never establishes event compliance.

## How to use the research

1. Identify the exact event edition, track, and presentation type.
2. Open the current official presenter/author page rather than relying only on this dated summary.
3. Confirm slot and speaking duration, aspect ratio/pixel dimensions, live versus pre-timed delivery, upload naming/codec/audio rules, AV connector, and accessibility expectations.
4. Record the current URL and verification date in project notes or a delivery checklist.
5. Change the deck or export process only when an official source establishes the requirement.
6. Rehearse the actual delivery route and keep an offline fallback.

Unknown or format-dependent rules remain unknown. Do not fill them from a previous edition, a different track, a workshop, or a remote fallback page.

## Boundary from visual styles

Event pages reviewed here mostly specify logistics rather than fonts, palettes, or slide templates. Do not invent event branding. Add official marks only when the current assets, license, and usage rules permit it and the author deliberately requests them. Style selection and rendering are documented elsewhere; this directory contains no style or profile instructions.

## House pacing guidance

When an event gives only a slot duration, plan to finish early enough for changeover and uncertainty. One main claim slide per 45-75 seconds is a rough starting estimate, not a rule. Rehearsal is authoritative; video, derivations, audience interaction, and 2D navigation all change pacing.
