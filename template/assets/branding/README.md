# Affiliation marks

The KAIST and Interactive Robotic Systems Laboratory PNG marks were supplied by the repository owner on 2026-08-25 for affiliation use in this presentation starter.

They are displayed without recoloring on a neutral plate so their original artwork remains legible in every Sinew profile. These files are not licensed under the repository's software license merely by being present here. Authors must confirm that their intended use follows the institutions' current identity and trademark rules, and must replace or remove the marks when preparing a deck for a different affiliation.
